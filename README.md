# Maximiliano Michasevich

Diseñador y desarrollador web en Montevideo, Uruguay.

Hago páginas web a medida para negocios y emprendedores: rápidas, pensadas
primero para el celular y con un diseño propio para cada cliente. Me encargo
de todo el proceso, desde la idea y el diseño hasta la publicación, el
dominio y el mantenimiento.

**Sitio web:** [michasevich.com](https://michasevich.com)

## Qué hago

- Páginas institucionales y landing pages
- Tiendas online y sistemas de pedidos
- Formularios, bases de datos y paneles simples
- Rediseño, velocidad y seguridad de sitios existentes
- Publicación, dominio y mantenimiento
